# Проект: Анализ успешности компьютерных игр на основе данных интернет-магазина «Стримчик»


**Цель проекта:**
* Выявить потенциально популярный продукт для последующего планирования рекламных кампаний


**Задачи проекта:**
* Выявить закономерности, определяющие успешность игры
* Отработать принцип работы с данными для их дальнейшего приминения при прогнозированнии продаж и планировании рекламных кампаний

**План проекта:**
* Загрузка и обзор полученных данных
* Предобработка данных
    * Переименование столбцов
    * Преобразование типов данных
    * Обработка дубликатов
    * Обработка пропусков
    * Расчет суммарных продаж во всех регионах
* Исследовательский анализ данных
    * Выпуск игр по годам
    * Изменение продаж по платформам
    * Определеить актуальный период
    * Определить какие платформы лидируют по продажам
    * Определить несколько потенциально прибыльных платформ
    * Boxplot для глобальных продаж игр в разбивке по платформам
    * Определить влияние на продажи внутри одной популярной платформы отзывов пользователей и критиков
    * Построить диаграмму рассеивания и посчиитать корреляцию между отзывами и продажами
    * Общее распредление игр по жанрам
        * Самые прибыльные жанры
        * Жанры с высокими и низкими продажами
* Составить портрет пользователя каждого региона
    * Самые популярные платформы (топ-5). Описать различия в долях продаж
    * Самые популярные жанры (топ-5). Пояснить разницу
    * Определить влияние рейтинга ESRB на продажи в отдельном регионе
* Проверить гипотезы
    * Средние пользовательские рейтинги платформ Xbox One и PC одинаковые
    * Средние пользовательские рейтинги жанров Action (англ. «действие», экшен-игры) и Sports (англ. «спортивные соревнования») разные
* Написать общие выводы

**Исходные данные:**
* Предоставлен датасет, содержащий исторические данные о продажах игр, оценки пользователей и экспертов, жанры и платформы (например, Xbox или PlayStation)
* Описание данных:
    * ``Name`` — название игры
    * ``Platform`` — платформа
    * ``Year_of_Release`` — год выпуска
    * ``Genre`` — жанр игры
    * ``NA_sales`` — продажи в Северной Америке (миллионы проданных копий)
    * ``EU_sales`` — продажи в Европе (миллионы проданных копий)
    * ``JP_sales`` — продажи в Японии (миллионы проданных копий)
    * ``Other_sales`` — продажи в других странах (миллионы проданных копий)
    * ``Critic_Score`` — оценка критиков (максимум 100)
    * ``User_Score`` — оценка пользователей (максимум 10)
    * ``Rating`` — рейтинг от организации ESRB (англ. Entertainment Software Rating Board). Эта ассоциация определяет рейтинг компьютерных игр и присваивает им подходящую возрастную категорию.

### Выводы по результатам проекта

<ins>**Общая информация о датасете**<ins>
* Получен датасет содержащий 16175 записей с 11 признаками. В целом датасет представляет из себя набор записей, состоящих из:
    * Наименование игры
    * Платформа
    * Жанр
    * Продажи в 3-х регионах (Северная Америка, Европа, Япония)
    * Продажи в прочих регионах
    * Оценка критиков
    * Оценка пользователей
    * Рейтинг игры

<ins>**Предобработка данных**<ins>
* **Обработка пропусков и дубликатов**
    * Больше всего пропусков в стобцах ``critic_score`` (53%), ``user_score`` (41%), ``rating`` (42%)
    * Пропуски по году релиза игры (``year_of_release``) восстановлены на основе годов релиза данной игры на других платформах, а полностью отсутствующая информация заполнена с использованием внешних источников данных.
    * Пропуски по полю rating заполнены значением 'unknown'
    * В поле ``user_score`` обнаружены текстовые метки 'tbd' - заменены на NaN, чтобы в дальнейшем можно было работать с данным полем как с числовым.
    
    * Явные дубликаты в датасете не обнаружены.
    * По связке значений наименование игры - платформа найдены 4 неявных дубликата - информация в дубликатах в части жанра, оценок и рейтинга одинаковая, отличаются только данные по продажам в регионах. Данные записи удалены из датасета.
    
    * Большинство пропусков в датасете находятся в полях с оценками пользователей, критиков и возрастным рейтингом. Это может быть связано со следующим рядом причин:
        * Отсутствие рецензий / обзоров на игры
        * Региональные особенности - как например с рейтингом ESRB, который актуален только для США и Канады
        * Технические ошибки или сбои при сборе данных, например некорректный парсинг.
        * Могли использоваться разные источники информации, так в разных источниках часть информации может отсутствовать.
    
    
* **Преобразование типов данных**
    * ``year_of_release`` - год преобразован в из вещственного типа к целочисленному
    * ``user_score`` - оценка пользователей преобразована из текстового типа в вещественный


* **Расчет суммарных продаж во всех регионах**
    * Добавлен новый столбец ``total_sales``, содержащий общие продажи по всем регоионам.


<ins>**Исследовательский анализ данных**<ins>

**Выпуск игр по годам**
* В 1990 году начался бум выпуска компьютерных игр, что вероятно связано с появлением персональных компьютеров для широкого круга потребителей и в целом с развитием электронных устройств.
* Рост количества выпускаемых игр продолжался до 2008 года, после чего пошел на спад. Согласно справке из открытых источников, с 2008 года наблюдалось структурное измененение рынка видеоигр - концентрация производства в крупных студиях, увеличение числа мобильных игр и игр-сервисов, а также смещение акцента на качество и большие бюджеты ААА-проектов.

**Изменение продаж по платформам**
* Начиная с 2006 года начинается тренд на сокращение представленности платформ и распределение рынка между 2 основными игроками - PlayStation (PS3, PS4) и Xbox (X360), в итоге к 2016 году из топ-платформ остались только они:
    * PS4 - 60%
    * PS3 - 17%
    * X360 - 22%
    
* До 2000 года новые платформы появлялись каждые два года, после 2000 года это период увеличился до 4-х и более лет.
* PS - платформа долгожитель, просуществовала на рынке 19 лет
* В среднем платформа держится на рынке около 13 лет.
    
**Влияние отзывов пользователей и критиков на продажи на платформе**
* Связь между отзывами пользователей и продажами практически отсутствует или крайне мала
* Связь между отзывами критиков и продажами - умеренная положительная, т.е. с ростом оценки критиков в среднем растут и продажи.

<ins>**Проверка гипотез**<ins>

**Гипотеза о равенстве средних пользовательских рейтингов Xbox One и PC**
* Оценки пользователей для платформ XOne и PC распределены ненормально, оба скошены влево, большинство значений концентрируются в диаозоне 6-8.
* В качестве критерия для проверки использовался t-тест.
* Тест показал, что нет статистически значимой разницы средней оценки пользователей для платформы XOne и PC.


**Гипотеза о неравенстве средних пользовательских рейтингов жанров Action и Sports**
* Распределения оценок двух жанров отличаются.
    * Распределение оценок для жанра Action скошено влево. Большинство значений находится в диапозоне 6-8. Мало оценок ниже 5-6.
    * Распределение оценок для жанра Sports выглядит более равномерным, с несколькими пиками.
    * Из распределения видно, что пользователи оценивают жанр Action выше чем Sports.
* В качестве критерия для проверки использовался t-тест.
* Тест показал, что существует статистически значимая разница средней оценки пользователей для жанров Action и Sports. Следовательно, предположение о разности пользовательских рейтингов в жанрах Action и Sports подтвердилось.


**Принцип формулирования нулевой и альтернативной гипотез**
* Нулевая гипотеза — это утверждение об отсутствии эффекта, различия или связи. Она предполагает, что наблюдаемые различия случайны и статистически незначимы. $H_0$ формулируется так, чтобы ее можно было опровергнуть.
* Так в примере с гипотезой о равенстве средних пользовательских рейтингов Xbox One и PC в качестве нулевой гипотезы определили гипотезу о том что средние оценки равны (нет статистически значимой разницы), альтернативную гипотезу сформулировали как противоположную нулевой - есть статистически значимая разница в средних оценках для двух платформ.
* В примере с гипотезой о неравенстве средних пользовательских рейтингов жанров Action и Sports нулевую гипотезу сформулировали так, чтобы проверить сначала отсутствие статистически значимой разницы средних оценок для двух жанров, а в качестве альтернативной гипотезы - противоположную нулевой, то есть отклоняя или не отклоняя нулевую гипотезу, мы подтвердим или опровергнем утверждение о разности средних оценок для двух жанров. 


**Обоснование выбора критерия для проверки гипотез**
* В качестве критерия для проверки гипотез был выбран t-test для независимых выборок по следующим причинам:
    * t-тест непосредственно предназначен для сравнения средних значений. Он позволяет оценить, насколько велика разница между выборочными средними и насколько вероятно, что эта разница обусловлена случайностью, а не реальным различием в генеральных совокупностях.
    * подходит для выборок небольшого объема, а при увеличении объема выборки t-распределение приближается к нормальному.
    * простота интрпретации - t-test дает t-статистику и p-значение. t-статистика отражает величину различия между средними, а p-значение — вероятность получить наблюдаемую разницу, если бы на самом деле средние были равны (нулевая гипотеза)
